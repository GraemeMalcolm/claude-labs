# Claude Labs

This repo contains exercises and supporting files for building AI agents with the Claude platform.

- **Instructions/Labs/** - the lab instructions.
- **computer-history-client/** - the starter code used in the first lab, to build a Message API based agent.
- **computer-history-tools-client/** - the starter code used in the second lab, to extend the Message API based agent with tools.
- **computer-history-mcp-client/** - the starter code used in the third lab, to connect the agent to a Wikipedia MCP server.
- **managed-agent-client/** - the starter code used in the fourth lab, to rebuild the agent as a managed agent.
- **test-images/** - images to use when testing image input.

> **Note**: The lab requires a Claude Console account with API credits. Never commit a real API key - the *.env* files in this repo contain placeholders only.

If you encounter any problems when completing the lab, please submit an [issue](../../issues).
